# Music AI Studio — ABC Edition

An HTML page that pairs a Gemini chat assistant with an
[ABC notation](https://abcnotation.com/) score editor. Ask the assistant for
melodies, harmonic analysis, or arrangement ideas; have it write directly
into the score; play the result in the browser; and export it as a
standard MIDI file.

No build step, no server, no account beyond your own Gemini API key —
just open `music_ai_studio_abc.html` in a modern browser
(Chrome or Edge recommended for full file-saving support).

## Features

- **Two-pane layout** — a chat pane on the left, an ABC text editor on the
  right, both visible at once.
- **Conversation memory** — the chat history (your requests and the
  model's replies) is sent to Gemini with every message, so it keeps
  context across turns. The current score is attached only to the
  message you're sending, not repeated for every past turn, to keep
  token usage in check.
  - Toggle with the "Memory" checkbox.
  - "Forget" clears the history without touching the visible chat log.
  - History is capped at 40 messages (20 exchanges); the oldest are
    dropped first.
- **Two chat modes**
  - *Free chat*: the model can explain, suggest, or discuss freely.
  - *Write to canvas*: the model's reply is inserted as-is into the
    editor (replacing everything, or at the cursor) — useful for
    "compose me a 8-bar melody in D minor" style requests.
- **Playback in the browser** with the
  currently-playing note in the editor.
- **MIDI export** — the "Save MIDI" button writes a standard `.mid` file
  to disk, one instrument per voice.
- **Multi-instrument, multi-voice scores** — instruments are chosen
  purely through ABC notation, with a `%%MIDI program N` directive right
  after each `V:x` voice declaration. There's no separate instrument
  picker in the UI by design; it keeps voice/instrument assignment
  unambiguous and lets you copy scores in and out of other ABC tools
  without losing anything.
- **File handling** — New / Open / Save for `.abc` files, using the
  native "Save As" file picker when the browser supports it (falls
  back to a regular download otherwise).

## Getting started

1. Open the HTML file in your browser.
2. Pick a Gemini model from the dropdown and click **Connect**. You'll
   be prompted for a Gemini API key — it is sent only to Google's
   Generative Language API and is never stored or sent anywhere else.
3. Type a request in the chat box (e.g. *"Write a cheerful 16-bar tune
   for flute and cello in G major"*), check **Write the reply into the
   canvas** if you want it inserted directly, and send with the button
   or Ctrl+Enter.
4. Click **Play** to hear it, **Save ABC** or **Save MIDI** to export it.

## Choosing instruments

Add a `%%MIDI program N` line right after each voice's `V:x` line:

```
X:1
T:Demo duet
M:4/4
L:1/8
K:C
V:1 name="Flute"
%%MIDI program 73
CDEF GABc | c2 B2 A2 G2 | F2 E2 D2 C2 | C8 |
V:2 name="Cello"
%%MIDI program 42
C,2 G,2 C,2 G,2 | C,2 G,2 C,2 G,2 | F,2 C,2 G,2 C,2 | C,8 |
```
Note: You can copy the scores generated by the LLM in the chat log and paste them into the canvas. 
Remove any blank line in the scores, just in case.

Common General MIDI program numbers: `0`=Piano, `24`=Guitar, `40`=Violin,
`42`=Cello, `56`=Trumpet, `71`=Clarinet, `73`=Flute. The assistant knows
this convention and will use it automatically for multi-voice requests.

## Notes on the MIDI export

`abcjs`'s built-in MIDI generator always writes program-change (instrument)
events on MIDI channel 0, even though each voice's notes play on their own
channel. Left as-is, every voice would sound like the same instrument in
an external MIDI player. This page includes a small post-processing step
(`fixMidiProgramChannels`) that rewrites each program-change event to the
channel actually used by its voice's notes, so the exported `.mid` file
plays back correctly outside the browser (DAWs, notation software, other
MIDI players).

## Requirements

- A modern desktop browser with Web Audio support for in-browser playback.
- A Gemini API key (from [Google AI Studio](https://aistudio.google.com/))
  for the chat assistant. Playback, editing, file open/save, and MIDI
  export all work without a key — only the chat features need one.
- An abcjs file for ABC music notation. 
  Download the content of  ' https://cdnjs.cloudflare.com/ajax/libs/abcjs/6.7.0/abcjs-basic-min.js ' and save it as abcjs.js. 
  The abcjs.js file must be in the same folder with HTML file. 


## Privacy

The API key is kept in memory only (via a prompt dialog) and is sent
directly from your browser to Google's Generative Language API — it is
never transmitted anywhere else or persisted to disk.
